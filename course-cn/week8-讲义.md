## 作业概览
用 3 种不同的技术栈构建同一个功能等价的 Web 应用。其中至少一个版本必须使用 [`bolt.new`](https://bolt.new/) 这一 AI 应用生成平台创建。至少一个版本必须在前端或后端使用非 JavaScript 语言（例如 Django、Ruby on Rails）。

你可以复用前几周的应用（即“开发者控制中心”），也可以自选一个新应用，只要它满足[最小功能范围](#minimum-functional-scope)。应用应当是端到端可用的（前端 + 后端 + 适用时的持久化），并展示出一套连贯的功能集。

## 最小功能范围
- 用户可以创建、读取、更新、删除一个主要资源（例如笔记、任务、帖子）。
- 具备适合该技术栈的持久化存储（数据库或基于文件）。
- 基本的校验与错误处理。
- 简单但可用的界面，能呈现主要流程。
- 清晰的本地运行说明（如已部署，附部署链接）。

## 技术栈要求
为同一个应用构建 3 个独立版本，每个版本使用不同的技术栈。示例：
- MERN（MongoDB、Express、React、Node.js）
- MEVN（MongoDB、Express、Vue.js、Node.js）
- Django + React（或 Vue）
- Flask + 原生 JS（或 React）
- Next.js + Node（或 NestJS）
- Ruby on Rails（全栈）

再次提醒：至少一个版本必须在前端或后端包含非 JavaScript 语言（例如 Python/Django、Ruby/Rails）。

至少一个版本必须使用 AI 应用生成平台 **[`bolt.new`](https://bolt.new/)** 构建，但其他版本也可以自由探索其他应用生成平台（例如 Lovable、Figma Make）。

## 了解 Bolt
Bolt 是一个 AI 辅助开发平台，可根据自然语言提示生成网站、Web 应用和移动应用。用户用纯文本描述自己的想法，Bolt 便能在几分钟内产出可用的原型——从落地页、电商站点到 CRM 和移动端工具。更多信息见[这里](https://support.bolt.new/building/intro-bolt)。

## 使用 AI 应用生成器的建议
- 像 Bolt 这类应用生成器最适合现代全栈技术；不指定具体框架时，默认就会得到这类技术栈。
- 最好从一个干净的提示开始，描述你的应用概念、实体、路由和界面流程。
- 在提示中清楚描述数据模型及其关系。
- 针对数据模型、CRUD 端点、鉴权（若使用）和前端组件，迭代优化提示。
- 让各个版本彼此隔离，避免依赖冲突。
- 导出或同步生成的代码，并作为该技术栈的独立项目文件夹提交。
