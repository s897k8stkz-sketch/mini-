# 翻译规范（TRANSLATION-SPEC）

本文件是 C1 流水线的翻译契约。所有译文必须遵守，以便术语表与一致性校验通过。

## 1. 输入与输出

- 输入：`source-cs146s-fall2025/weekN/assignment.md`（英文原文，由 `fetch_sources.py` 拉取）
- 输出：`course-cn/weekN-讲义.md`（简体中文译文）

## 2. 强制规则

1. **术语一致性**：`glossary.csv` 中出现的英文术语，必须使用表中给出的中文译法。同一术语在同一份译文内不得出现两种译法。
2. **不删减**：原文的每个章节、标题、列表项、表格行都必须有对应中文。禁止用「略」「同上」「（其余省略）」等占位。
3. **代码块与命令保持原样**：` ``` ` 代码块内的代码、shell 命令、文件路径、URL、JSON 键名一律不翻译，只翻译代码块外与代码块内的注释。
4. **标题层级不变**：原文 `#`/`##`/`###` 的层级与数量与译文一一对应。
5. **保留可检索锚点**：文件顶部保留一行 `> 原文：<相对路径> ；上游提交：见 source/PINNED.txt`。
6. **专有名词保留原文**：产品名、平台名、人名（Claude Code、mitmproxy、Anthropic、Gradescope、Stanford、CS146S 等）保留英文。
7. **链接原样保留**：Markdown 链接的 URL 不改写，链接文字翻译成中文。
8. **语气**：面向中文学习者，使用陈述式技术中文，不使用口语化表达，不加译者个人评论。

## 3. 交付格式

```markdown
# 第 N 周：<中文标题>

> 原文：weekN/assignment.md ；上游提交：见 source/PINNED.txt

<正文……>

---
*本译文由 C1 翻译流水线产出，术语以 `glossary.csv` 为准。*
```

## 4. 自检清单（产出前必须逐条确认）

- [ ] 译文中的章节数 ≥ 原文章节数
- [ ] 引用的术语全部来自 `glossary.csv`
- [ ] 没有残留的英文整句（代码块、专有名词、URL 除外）
- [ ] 没有 `TODO` / `略` / `省略` 占位
